# TalentLens AI (HireSense)

An AI-powered context-aware resume screening and candidate preparation platform built with a real-time reactive backend. TalentLens bridges the gap between recruiter evaluation and candidate job discovery through intelligent ATS matching.

---

## 🚀 Key Features

### 🏢 Recruiter Portal
- **Job Creation & Management:** Post open engineering roles with target skill requirements in real time.
- **Applicant Ranking:** Live applicant list ranked automatically by ATS match score.
- **Instant Candidate Evaluation:** Review submitted resumes and candidate profiles without page refreshes.

### 👤 Candidate Portal & Screening
- **Application Submission:** Candidates can submit profiles and resume summaries for active job openings.
- **Automated ATS Scoring:** Real-time screening engine evaluates applicant skill depth against role requirements.
- **Preparation & Feedback:** Pre-screening feedback loop to help candidates analyze skill matches.

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS, Lucide Icons
- **Backend & Database:** Convex (Real-time reactive document store & serverless functions)
- **Tooling:** Vite, VS Code, Git

## 📦 Getting Started

### 1. Clone the repository
\`\`\`bash
git clone https://github.com/trishapandey-123/talentlens-AI.git
cd talentlens-AI
\`\`\`

### 2. Install dependencies
\`\`\`bash
npm install
\`\`\`

### 3. Run the development server
\`\`\`bash
npm run dev
\`\`\`

### 4. Run the Convex backend
\`\`\`bash
npx convex dev
\`\`\`
